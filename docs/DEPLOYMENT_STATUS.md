## 📋 技术决策记录

### FaceEmbed API部署方式
- **决策**: 使用原生Python部署，不使用Docker
- **原因**: 
  1. Hailo硬件需要直接PCIe访问
  2. 容器化会增加延迟和复杂度
  3. 边缘设备资源有限，原生部署更高效
- **结果**: 推理性能达到3-18ms，满足生产要求

### Docker Compose简化
- **决策**: 移除FaceEmbed API容器，仅保留主服务器服务
- **影响**: 部署更简单，调试更方便
- **配置**: 所有参数集中在Node-RED中管理
